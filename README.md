# Weiheng Li Homepage

Personal academic homepage inspired by a lightweight GitHub Pages style.

## Local Preview

Open `index.html` in a browser.

## GitHub Pages Setup

1. Create a repository on GitHub named `HenryPotter0546.github.io` for a user homepage, or use another repository name for a project homepage.
2. Push this folder to that repository.
3. If using a project repository, enable GitHub Pages from `Settings -> Pages` and choose the `main` branch.

## Files

- `index.html`: page structure and content
- `styles.css`: visual style and responsive layout
